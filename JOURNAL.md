# Journal des requêtes

## Palier 2

1. Le classement indique les meilleurs scores de chaque partie.
2. Le top 3 permet de comparer les meilleurs joueurs dans chaque partie.
3. Le cumul montre comment le temps de jeu augmente chaque mois.
4. La comparaison en pourcentage montre si le nombre de parties augmente ou baisse.
5. La part du total compare les points de chaque joueur à tous les points.
6. La moyenne mobile lisse les différences de durée entre les parties.

## Palier 3

1. La première requête trouve les joueurs dont le total de points dépasse la moyenne.
2. La deuxième repère les mois dont la durée totale dépasse la moyenne mensuelle.
3. La récursivité affiche les équipes et leurs sous-équipes.
4. Le calendrier fait ressortir les jours sans partie.

## Palier 4

1. Le tableau croisé compare le nombre de parties des trois mois.
2. Le `ROLLUP` affiche les résultats par mois et leur total général.
3. La moyenne et la médiane devraient être proches, car les durées ont été générées au hasard dans une plage fixe ; la médiane reste moins sensible aux valeurs extrêmes.
4. Le tableau de bord rassemble le nombre de parties et le temps de jeu cumulé par mois.
